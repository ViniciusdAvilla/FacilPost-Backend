# FácilPost · API de publicações

API FastAPI do calendário de Páginas do Facebook. A conexão usa OAuth da Meta. O servidor obtém as Páginas autorizadas, envia publicações à Graph API e consulta os posts publicados e agendados para o intervalo do calendário.

O agendamento é enviado à Meta. As métricas de cada publicação incluem reações, comentários e compartilhamentos quando disponíveis.
